# Vendored design system

`tokens.css`, `bundle.css`, `bundle.js` and `index.d.ts` are copied unchanged from `docs/design_system.zip`
(`Dog-Ear/tokens.css` and `Dog-Ear/components/*`). They are generated by the design tool, so do not edit them here.

- `index.js` is the app's entry point: it sets `window.React`, runs the bundle, loads the CSS and re-exports
  every component from `window.DogEar` as a named ES export (`import { Button } from './design-system'`).
- Prop types live in `index.d.ts`; long-form usage notes are in the zip's `components/*/README.md`.
- App-level adaptation (real viewport heights, fixed overlays, safe areas, the accessibility fixes) lives in
  `src/app.css`, never in these files.

To update: export a new zip into `docs/`, then copy the four files over these and check the app.

```bash
unzip -o docs/design_system.zip -d /tmp/ds && cp /tmp/ds/Dog-Ear/tokens.css /tmp/ds/Dog-Ear/components/{bundle.css,bundle.js,index.d.ts} src/design-system/
```
